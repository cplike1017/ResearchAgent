# 数据分析技能

当用户请求数据分析时，按以下流程执行：

## 1. 数据获取
- 确认数据来源：文件（file_read / sqlite_query）、网络（fetch）或用户提供。

## 2. 分析流程
- 描述数据概况：条数、字段、缺失值
- 关键统计量：均值、中位数、分布
- 找出异常值与趋势

## 3. 输出格式
- 用 markdown 表格呈现统计结果
- 给出 2-3 条关键洞察（insight）
- 附可视化建议（图表类型 + 展示的字段）

## 4. 结论
- 用一句话总结数据告诉我们什么
- 指出数据局限性（如果有）
