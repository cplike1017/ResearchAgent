# Code Review 技能

当用户请求审查代码时，按以下流程执行：

## 1. 获取代码
- 如果用户贴了代码，直接使用；否则询问代码位置或用 file_read / GitHub 工具获取。

## 2. 审查维度（逐项检查）
- **正确性**：边界条件、空值处理、逻辑错误
- **安全**：注入、敏感信息泄露、不安全的调用
- **性能**：不必要的循环、低效的数据结构
- **可读性**：命名、复杂度、重复代码
- **健壮性**：异常处理、资源释放

## 3. 输出格式
用结构化列表输出，每条包含：
- 严重程度（[高]/[中]/[低]）
- 位置（文件:行）
- 问题描述
- 建议修复

## 4. 结尾
给出总体评价（1-5 分）和最重要的 3 个改进点。
